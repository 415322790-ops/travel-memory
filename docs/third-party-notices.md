# 第三方参考说明

## film-index-generator

项目根目录下的 `film-index-generator-main` 是本地参考项目，仅用于胶片页面的交互和视觉研究，不纳入当前旅行网站 Git 仓库。该目录保留在本机，未被删除、移动或修改。

正式旅行网站的胶片功能位于 `src/components/ItineraryFilmView.jsx`、`src/components/ItineraryPhotoTools.jsx` 和相关样式文件中；这些文件不直接从 `film-index-generator-main` 导入运行时代码。若后续继续改编参考项目中的实质代码，应继续保留以下 MIT 许可声明。
