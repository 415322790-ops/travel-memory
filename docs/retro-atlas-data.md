# Retro Atlas Data

The `retro-atlas` globe uses a local high-resolution Natural Earth II raster
with a restrained parchment-paper treatment through Cesium's single-tile
imagery provider.

- Source: Natural Earth II with Shaded Relief, Water, 50m source raster
- Source dimensions: 10800 x 5400
- Projection: global plate carrée / equirectangular, 2:1
- Runtime texture: `public/retro-atlas/earth-retro-paper-8192.jpg`
- Runtime dimensions: 8192 x 4096
- Processing: high-resolution resampling plus a baked parchment palette and
  subtle fixed paper grain. No sharpening, CSS filter, or runtime contrast
  enhancement is used.
- Provider: Cesium `SingleTileImageryProvider`
- Current remastered runtime texture: `public/retro-atlas/retro-atlas-remastered-8192.jpg`.
  It bakes the approved mountain, terrain, graticule, equator, and tropical
  reference lines into one equirectangular texture so they are not added as
  separate runtime overlays.
- `VITE_RETRO_ATLAS_TEXTURE_MODE=legacy` can temporarily select the previous
  clean paper texture for comparison; the default is `remastered`.
- `VITE_RETRO_ATLAS_TEXTURE_MODE=segmented` selects an experimental, offline
  panel-calibrated linework variant generated by
  `scripts/generate-retro-atlas-segmented.py`. It keeps the high-resolution
  geospatial base and applies reference-map details per continent bounds.
- `VITE_RETRO_ATLAS_TEXTURE_MODE=reference-full` selects the full framed
  reference-map composition generated by
  `scripts/generate-retro-atlas-reference-full.py`. This mode intentionally
  retains all visible map artwork: labels, ships, sea creature, compass, grid,
  border, and parchment details.
- `VITE_RETRO_ATLAS_TEXTURE_MODE=reference-restored` selects the sharper
  restored candidate generated from the supplied reference image. It keeps
  the same complete artwork while using a separately saved restoration source;
  the original reference and `reference-full` output remain available.
- Layer 1 overlay: `public/retro-atlas/earth-retro-mountains-8192.png`
- Layer 2 overlay: `public/retro-atlas/earth-retro-terrain-lines-8192.png`
- The Layer 1/Layer 2/Layer 3 environment switches remain available for the
  legacy comparison mode; remastered mode uses the baked details and does not
  create those extra Cesium imagery layers.
- Layer 3 overlay: `public/retro-atlas/earth-retro-graticule-8192.png`, using a
  sparse 20-degree geographic graticule with no labels.
- The previous blue/green Natural Earth runtime texture and the 2000 x 1119
  user reference remain in the asset folder for comparison only and are not
  used by the runtime.
- Satellite mode continues to use the existing ArcGIS provider.
